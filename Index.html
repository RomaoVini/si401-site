Sobre a Disciplina

A disciplina aborda os principais conceitos e tecnologias utilizadas no desenvolvimento de aplicações para a Web. Durante as aulas, os alunos aprendem a criar páginas web utilizando HTML e CSS, além de desenvolver funcionalidades interativas com JavaScript.

Também são apresentados conceitos relacionados à geração dinâmica de páginas e ao desenvolvimento de aplicações que utilizam servidores web, permitindo compreender a integração entre front-end e back-end.

Objetivo

O objetivo da disciplina é apresentar os fundamentos da programação para Web, capacitando os alunos a compreender e utilizar linguagens de marcação, folhas de estilo e linguagens de programação tanto no navegador quanto no servidor.

Metodologia

As atividades são realizadas por meio de aulas teóricas e práticas, combinando a apresentação dos conceitos com exercícios e implementação de sistemas baseados nas tecnologias estudadas.

Competências Desenvolvidas

Ao longo da disciplina, o aluno desenvolve conhecimentos para:

  • Compreender o funcionamento de aplicações Web baseadas na arquitetura cliente-servidor;
  • Criar páginas web estáticas utilizando HTML e CSS;
  • Desenvolver páginas web dinâmicas utilizando JavaScript;
  • Compreender o funcionamento de scripts executados em servidores web;
  • Desenvolver aplicações Web completas, integrando front-end e back-end.

Pré-requisito

Para cursar a disciplina, é necessário ter concluído SI300 – Programação Orientada a Objetos I.

Frequência

É necessário ter frequência mínima de 75% nas atividades da disciplina.

Exame

O exame é obrigatório para alunos cuja média final esteja no intervalo 2,5 ≤ M < 6,0, conforme os critérios de avaliação da disciplina.
